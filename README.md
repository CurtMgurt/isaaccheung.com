# isaaccheung.com

Temporary hosting for the selected Curtis Cheung pixel arcade preview.

The page uses the v7 artwork with Vincent's Numbered world poster and Sudo's
portrait. It includes links to Vincent and Calvin, ambient animation, a
pause/play control and reduced-motion support. Assets are self-hosted and the
preview is marked noindex. No build step or external runtime dependency.

GitHub Pages publishes the root of main at isaaccheung.com; retain CNAME and
.nojekyll. The previous Isaac coming-soon page is preserved in Git history at
8df78afc2f3d2639969c875477765aa414343f1b for restoration after the preview.

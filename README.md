# Curtis pixel room preview

Temporary preview for isaaccheung.com. The Vincent site remains separate.

Open index.html through a local HTTP server. Both machines link to their player sites. The scene uses a 1536×1024 plate, a transparent cat pose atlas, one flipper sprite, and the unchanged supplied family photo inside its original frame.

The canvas runs at 30 fps and 768×512 pixels. Native painted lamps have cached dim and bright variants; the ball and flippers share a timed path. Steam is filled vapor rather than strokes. Pausing freezes all motion together; reduced-motion settings start with a still scene. Hidden or offscreen scenes suspend animation.

Assets and prompt provenance are recorded in asset-notes.json. Rejected face and cat drafts are preserved outside the published files.

The previous Isaac coming-soon page is preserved at commit 8df78afc2f3d2639969c875477765aa414343f1b in the Isaac repository. To restore it, revert the temporary preview commits while retaining CNAME and .nojekyll.
